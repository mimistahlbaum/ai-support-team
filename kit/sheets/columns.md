# What the columns mean

Dates are written YYYY-MM-DD (for example 2027-03-15), so they sort correctly and cannot be misread across countries.

## Opportunities

One row per open call: a grant, residency, audition, commission, prize or expression of interest.

| Column | What goes in it |
|---|---|
| Name | The name of the call, as the organiser writes it |
| Organiser | Who runs it |
| Official link | The organiser's own page for this call. Not a newsletter, listing site or social media post |
| Deadline | The closing date (YYYY-MM-DD) |
| Deadline checked? | **Checked** only after someone has read the date on the official page. Otherwise **Not checked** |
| Time and time zone | The time and time zone of the deadline, if given (for example 5pm AEDT) |
| Who can apply | Eligibility in short, with the words from the official page where possible (for example "Open to artists of any nationality") |
| Amount | The money offered, with currency, if stated |
| Found on | The date you added the row (YYYY-MM-DD) |
| Status | One of: **Idea**, **Read**, **Will apply**, **Applied**, **Waiting**, **Successful**, **Unsuccessful**, **Not applying** |
| Result or decision date | When the result is due, or when you decided (YYYY-MM-DD) |
| Notes | Anything else: where you heard of it, questions, what changed |

Keep every row, including the ones you did not apply for. Over a year this shows what you looked at, what you applied for and what came of it.

## Deadlines

One row per thing you must send, submit or answer by a date. Leave out things that are someone else's job, and optional things you have decided to skip.

| Column | What goes in it |
|---|---|
| What | What must be done, in a few words (for example "Send final artwork to the festival guide") |
| Due | The date (YYYY-MM-DD) |
| Time and time zone | If given |
| Where it comes from | The email subject and date, a link or "I decided" |
| Due date checked? | **Checked** if the date is written in the email or document that sets the task, or you read it there yourself. Otherwise **Not checked** |
| Status | **Open**, **Done** or **Not needed** |
| Notes | Anything else |

Do not delete rows when they are done. Mark them **Done**.

## Contacts

One row per person or organisation you actually work with. Not everyone who emails you.

| Column | What goes in it |
|---|---|
| Name | The person's name |
| Organisation | Where they work, if relevant |
| Role | Their role (for example "Venue manager") |
| Email or website | How to reach them |
| Relationship | One of: **Venue**, **Funder**, **Collaborator**, **Artist**, **Supplier**, **Audience**, **Other** |
| Last contact | The date of the last email or meeting (YYYY-MM-DD) |
| Waiting on | **Them**, **Me** or **Nothing** |
| Next step | What happens next, in a few words |
| Notes | Anything else |
