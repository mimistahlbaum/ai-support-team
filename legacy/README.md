# Legacy: the Discord multi-agent bot

This folder holds the first version of AI Support Team: a Discord bot in which five AI agents (Scout, Spark, Forge, Mirror and Coordinator) discussed each request and posted a summary.

It is kept for reference and is no longer developed. In practice, agent discussions added reading time instead of saving it. The kit in [`../kit`](../kit) replaces it.

The original setup notes are in [SETUP.md](SETUP.md). The code has not been changed since July 2026 and may need updates before it runs.
